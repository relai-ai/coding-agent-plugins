# Contributing

The plugin packages and catalogs here (`.agents/`, `.claude-plugin/`,
`.cursor-plugin/`, `plugins/`, `copilot/`, `artifacts/`, and `provenance.json`)
are generated by RELAI's release process, so don't edit them by hand; a pull
request that changes them fails validation. To report a problem or suggest a
change to the plugin, open an issue.

Changes to `.github/`, `scripts/`, and root documentation can be proposed
directly, in pull requests that don't touch generated files.

## Releases

Each release pull request records its source commit, file inventory, and digest
in `provenance.json`. Merged releases are tagged `vX.Y.Z`; the post-merge
workflow publishes the Copilot skills and attaches the OpenAI archive to the
GitHub Release.
